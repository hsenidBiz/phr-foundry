# Required Output Contract

1. Requirement and supplied-SQL understanding
2. Module, folder, and work metadata
3. Detected index evidence
4. Created file and deployment registration
5. Generated guards and scaffolding
6. Source-SQL preservation result
7. Localization result, when applicable
8. Validation queries and checks, reported outside deployment SQL files
9. Risks, rollback notes, or blockers

Do not claim completion when required input, source-SQL preservation, validation, or exact `dep.xml` registration is missing.
